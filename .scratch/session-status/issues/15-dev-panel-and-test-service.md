# 15: 测试能力移出主插件：注册测试服务 + dev/ 独立调试插件

**Status:** done — 测试服务 Hook 已注册并有直测；主插件设置区随后在 afcd4c7 被彻底移除（用户要求），本票原文第 1 条与此冲突的说明见 Comments
**Blocked by:** None（可立即开始）
**Source:** GitHub #15（已从 GitHub 迁入本地工作系统）

## 背景

ADR-0002 把调试能力放在主插件里、用 `__DEBUG__` 构建期裁剪来对用户隐藏。用户否决了这个形态：测试代码应当与发布包**分离**（包更小、测试只属开发阶段），而且调试面板需要**双向**验证前台抑制规则——`testMode` 只能单向证明「能弹」，证明不了「前台时确实不弹」。

新决定记录于 **ADR-0003**（ADR-0002 已标 superseded）。

## 要做的

1. **主插件瘦身**：删除调试 UI、探针、测试模式与 `__DEBUG__` 构建分支；设置区回到正常使用者看到的那一行（说明文字 + 渠道/权限状态 + 发送测试提醒）。
2. **注册测试服务（唯一的 Hook）**：
   - `setForegroundOverride("auto" | "foreground" | "background")` —— **只**覆盖「当前页面是否在前台」这一个事实
   - `getSnapshot()` —— 只读诊断事实（状态源 / 最近边沿 / 最近投递 / 当前页面 `{visibility, focused, background}`）
   - `subscribe(listener)` —— 面板实时更新，返回退订函数
   - `deliverAdHoc(kind)` —— 走与自动提醒**完全相同**的投递路径（同 tag 序号、同桥状态、同权限、同诊断上报）
3. **`dev/` 独立调试插件**：主仓库内独立包，不进发布包（`files` 白名单排除）。面板含诊断 4 行 + 探针（test / interrupted / 连发 ×3）+ **前台三态开关**（跟随真实 / 强制前台 / 强制失焦）。
4. **文档同步**：SPEC 的实现决策与测试决策按新形态改写；CONTEXT 按需更新。

## 验收标准

- [ ] 强制前台 + 探针 → **不弹**，但诊断里留下「被前台抑制」的记录
- [ ] 强制失焦 + 探针 → **应弹**
- [ ] 前台覆盖**不影响**任何其它判定（等待/停止边沿、去重、抑制、静默）
- [ ] 行为测试（判定 / 投递 / 诊断 / 归一化 / 装配 / 读方）全部保持通过，期望值不得放宽；仅「调试能力」相关测试可随能力转移而删除或改写
- [ ] 报告产物大小前后对比
- [ ] `dev/` 面板不在发布包内（自证：`npm pack` 后检查 tarball 内容）
