# 测试能力移出主插件，由独立开发插件经测试服务接入

Status: superseded by [ADR-0004](0004-debug-tools-ship-with-the-plugin.md)（面板并回主包、默认关闭、挂在插件自己的页面）

诊断面板、探针与「模拟失焦」这类测试手段只属于开发阶段，不该随发布包分发。因此主插件**不再自带任何调试 UI**，也不再靠 `__DEBUG__` 构建期裁剪来隐藏它（ADR-0002 的做法）——取而代之的是主插件注册一个**测试服务**（Hook）：它只覆盖「当前页面是否在前台」这一个承重事实，并暴露只读诊断事实与一条**与自动提醒共用投递路径**的测试投递；`dev/` 下的独立调试插件 `inject` 该服务来渲染面板，不进发布包。

代价：主插件里仍留有一个服务注册点与一条前台覆盖通道（不是零测试相关代码），且调试面板需要额外安装 `dev/` 插件。收益：测试代码与发布包真正分离、包更小；面板能**双向**验证前台抑制规则（强制前台 → 不该弹但留下抑制记录；强制失焦 → 应该弹），而 ADR-0002 时代的 `testMode` 只能单向证明「能弹」。

## Considered Options

- **`__DEBUG__` 构建期裁剪**（ADR-0002）：正式包干净，但调试者与普通用户共用同一份安装——想用面板就得重新构建并重装，且面板无法在没有调试构建时使用。
- **测试代码与源码分离 + 测试服务 Hook**（本决定）：主插件只留接口，面板是独立插件；更彻底，并支持运行时切换前台状态做双向验证。
